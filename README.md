# Simple Interest Calculator

## Description
A calculator that computes simple interest given principal, rate of interest, and time period in years.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

[Instrucciones de cómo usar]

## Example
Principal: $1000
Rate: 5%
Time: 2 years
